# Syntonia — сайт

**Live:** <https://appacc77-dotcom.github.io/syntonia-site/> — GitHub Pages, публикуется из ветки `main` (корень репозитория).

Репозиторий содержит **только готовый статический сайт** и предназначен для доработок по отдельным задачам. Исходная генерация контента/вёрстки — в конвейере `studio-pipeline-v2` (m2 → m3 publish-pack); сюда приходит уже собранный статический комплект.

## Состав

- 24 страницы (`*.html`, включая `library/*.html`) + `404.html`;
- `assets/`, `fonts/` — ассеты сборки;
- `robots.txt` — `index, follow` + `Sitemap:`; `sitemap.xml` — 23 URL (без `not-found`);
- `.nojekyll` — отключает Jekyll (не удалять);
- `CHANGELOG.md` — история версий сайта.

## Как дорабатывать

1. Правьте HTML/CSS/ассеты прямо в `main` (или отдельной ветке + PR).
2. Проверьте локально: `python3 -m http.server` из корня (или любой статический сервер), ключевые страницы + 404.
3. Коммит в `main` → GitHub Pages автоматически пересоберёт и опубликует сайт (источник Pages — `main` / `/`).

Требования: не удалять `.nojekyll`, `404.html`, `robots.txt`, `sitemap.xml`; сохранять структуру ссылок (`library/`). Все правки контента/вёрстки — точечно, с проверкой затронутых страниц.

## Версии

Теги `vX.Y.Z` фиксируют публикации; текущая — `v0.9.0` (production-индексация). История — `CHANGELOG.md`.
