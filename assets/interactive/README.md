# Interactive ES modules

Модули progressive enhancement поверх SSG DOM. Подключаются только на нужных страницах:

```html
<script type="module" src="./assets/interactive/nav.js"></script>
```

Не редактировать минифицированный бандл, `reference/**` и сервисные скрипты m3.
Состояния сверять с QA-копиями fixtures/structure из reference.
