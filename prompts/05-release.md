# Промт 05 — релиз и публикация Pages

Задача:
1. Убедись, что `site.json`/CHANGELOG/VERSIONS отражают изменения и все страницы имеют статус.
2. Запусти `node scripts/prepare-pages.mjs` и проверь `.pages/`.
3. Подними версию (`vX.Y.Z`), обнови CHANGELOG, сделай commit и tag.
4. Опубликуй через GitHub Pages (`.github/workflows/pages.yml` или gh-pages).
5. Проверь публичный URL и запиши его в `site.json`/VERSIONS.
