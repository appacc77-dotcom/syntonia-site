# Приёмка Syntonia против эталона m2 (golden reference + Figma)

Документ фиксирует методику ворот, актуальные числа и **принятые остатки** — то, что осознанно
не доводится до нуля, потому что упирается в свойства рендерера/эталона, а не в код сайта.

```bash
cd site

```

## Принятые остатки (объяснены, не являются регрессом)

1. **Δh = ±1 px на 4 маршрутах** (masters, quiz, book-chapter-technique/story). Эталонные PNG
   имеют нечётную высоту по вертикали (например 7773 px при 2x = CSS 3886.5), а полноэкранный
   скриншот браузера при DPR=2 всегда чётный. Совпадение невозможно по построению; в m2 baseline
   остаток тот же.
2. **Полноэкранные фото/текстуры** (home hero, quiz hero, practice wood). Цветопередача декодера
   WebP/JPEG в Chromium и в рендерере эталона даёт субпиксельные различия на градиентах — это
   антиалиасинг/цветоуправление, а не позиция или контент (проверено замерами средних цветов:
   расхождение ≤0.2/255 на однородных участках).
3. **Тонкая кириллица Literata/Golos** на границах строк: ширина строки может отличаться на 1–3 px
   из-за хинтинга шрифта; перенос строк совпадает, позиции текста — в пределах ±1 px.
4. **color-contrast (axe, WCAG 2.1 AA)**: 118 узлов используют цвета текста из макета Figma
   (приглушённые оттенки на кремовом фоне). Изменение цветов нарушило бы пиксельную сверку,
   поэтому зафиксировано как дизайн-решение; все остальные правила axe — 0 нарушений.

## Что специально проверено и исправлено

- **Текст**: 1510 текстовых узлов сверены с `live-nodes.json` (содержание, кегль, интерлиньяж,
  трекинг, ширина бокса). Восстановлены жёсткие переносы строк, склеенные кодогеном
  (`data/text-breaks.json`): например H1 legal-refund (mean 2.09 → 1.26).
- **Геометрия**: точечные фиксы кодогена (`data/geometry-fixes.json`) — левая стрелка слайдера
  practice была на 48 px выше эталона (компенсирован `left`, не `top` под
  `rotate-[-180deg] origin-top-left`); стрелки слайдера форматов Home выставлены по макету
  (left/right 24 px, центр по вертикали).
- **Иконки**: 483 snapshot-SVG восстановлены, 20+ глифов переэкспортированы из Figma,
  183 override-узла (`data/icon-overrides.json` → `src/generated/vector-extra.css`);
  DS-fixtures 62/62.
- **Семантика**: h1 по одному на страницу, h2/h3 и порядок заголовков, `role="img"`/`aria-hidden`
  для декоративных изображений, JSON-LD (`@graph`: Organization/WebSite/WebPage/BreadcrumbList)
  на 24/24, `robots`/`noindex` для приватных страниц и 404, `lang`, `main`, skip-link.
- **Форма booking**: семантические поля, валидация, honeypot, `role="status"`, формат заявки из
  блока «Выбранный формат». Канал доставки **согласован владельцем (2026-11-19): mailto** на
  `hello@syntonia.com` — форма открывает почтовый клиент с готовым письмом и дублирует ссылки в
  статусе. Смена на POST-канал — одна строка `endpoint` в `site/data/form-config.json`
  (Formspree/Getform, Telegram-бот через Worker, Apps Script или свой сервис), код отправки готов.

## Качество изображений (пункт 0 DoD)

Проверка: все бинарные ассеты сайта сверены с исходными экспортами Figma по размерам и качеству
кодирования.

| Метрика | Результат |
|---|---|
| ассетов проверено (бин. файлы по asset-map) | **422** |
| изменений разрешения (даунскейл) | **0** — все native-размеры сохранены |
| JPG (в т.ч. фото авторов) | **byte-exact** с исходниками |
| WebP | near-lossless: mean Δ ≤ 0.35/255, max Δ ≤ 1 (визуально без потерь) |
| фото авторов (masters) | native: 1448×1086 и 1140×1392 (показ 570×730 → до 1.9× retina) |
| фото Екатерины (home/master) | native 1672×941 / 1752×1762; hero 1280×720 — native-размер макета |

Примечание: там, где native-разрешение макета меньше CSS-размера (hero 1280×720 на 1440 px),
это свойство исходника Figma, а не даунскейл сайта; апскейл рисуется так же, как в эталонном
рендере (golden). Реэкспорт из Figma выше native невозможен.

## Вес страниц и 2x-варианты (v0.11.12)

- Для мелких показов крупных фоновых изображений сгенерированы **2x-варианты** (кроп по аспекту
  для `cover`, resize до 2×`background-size` для явных px, WebP q90): плотность 2× на retina
  сохранена, пиксельная сверка не изменилась (golden-метрики идентичны, contract/a11y/fixtures PASS).
- Экономия веса: practice 28.8→25.7 МБ, masters 8.7→7.5 МБ, quiz 4.3→3.1 МБ, booking 4.8→3.5 МБ.
- Правила: `site/data/asset-variants.json` (node → вариант), ассеты `assets/img-*-<2x>.webp`.

## Иконки: сплошная сверка (v0.11.10)

- Проверены **376** иконных узлов на 8 страницах: цвет/позиция против golden, включая мелкие
  маркеры-точки. Исправлены точки-маркеры (color-режим override: заливка + радиус) и стрелки
  слайдера practice (плотность круга как в макете).
- Принятые остатки: субпиксельные точки 2–5 px (средний цвет бокса смешивается с фоном) и
  интерактивные состояния контролов (радио quiz в golden — выбранное состояние дизайна,
  в интерактиве начальное — невыбранное).
- DS-компоненты: fixtures design-system **62/62** (mean 1.47 %).

## SEO/соц-превью (v0.11.8)

- `og:image` уникален для маршрута: `social/og-*.jpg` 1200×630, JPEG (соцсети не везде читают WebP);
  плюс `og:image:width/height/alt`, `twitter:image`.
- Favicon: `icons/favicon-32.png`, `icons/apple-touch-icon.png` (180), `icons/favicon-512.png`,
  `theme-color` #3A3223; `Organization.logo` в JSON-LD указывает на favicon-512.
